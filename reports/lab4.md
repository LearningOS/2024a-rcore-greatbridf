# `root inode`起到什么作用

这是一个目录，里面放着这个目录下的所有的文件的数据，比如文件名和ino。

# 如果`root inode`损坏了会发生什么

那根目录的文件列表可能会出现错误，比如文件少了，或者是文件名等信息乱了。

# 使用`pipe`的一个实际应用的例子

如果要得到一个ELF文件的hexdump，保存一份，并且在终端中方便地查看，可以这样

``` sh
xxd executable | tee output.txt | less
```

# 更易用的多进程通信机制

可以搞一个工具，创建很多类似于unix socket的通道，然后每个进程都向这个socket写入数据以及希望发送到的进程，然后由这个工具进程将这些数据路由转发到每个进程。
